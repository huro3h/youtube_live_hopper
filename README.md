# YouTubeLiveHopper

YouTube Liveの視聴を快適にする便利機能を詰め合わせたChrome拡張機能です。

主な機能：

- **ライブヘッドへの自動シーク** — 配信ページを開くと自動で最新位置（ライブヘッド）までシーク
- **チャットの自動全表示** — チャット欄を「トップチャット」から「チャット（すべて表示）」へ自動切り替え

Chrome Web Storeには公開していないため、手動でインストールして使用してください。

---

## インストール

```bash
git clone git@github.com:huro3h/youtube_live_hopper.git
```

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. クローンしたフォルダを選択

---

## 使い方

インストールするだけで動作します。ライブ配信中の動画ページ（`youtube.com/watch?v=...` または `youtube.com/live/...`）にアクセスすると、自動で配信の最新位置までシークし、チャット欄を「すべて表示」に切り替えます。

Chromeツールバーの YouTubeLiveHopper アイコンをクリックすると、以下の設定を切り替えられます。

| 設定 | 説明 |
|------|------|
| 常に最新位置から再生 | OFFにすると自動シークを無効化できます（追っかけ再生をしたい場合など） |
| チャットを常に全表示 | OFFにするとチャットの自動切り替えを無効化できます（トップチャットのままにしたい場合など） |

---

## 仕組み

### ライブヘッドへの自動シーク（`content.js`）

1. `content.js` がYouTubeの動画ページに注入される
2. 動画ページ（`/watch` または `/live/`）へのアクセス・SPA遷移（`yt-navigate-finish`）を検知
3. プレーヤーに `.ytp-live-badge`（ライブバッジ）が表示されるまで待機（配信中でない動画では何もしない）
4. ライブバッジのクリックとプレーヤーAPI（`seekToLiveHead()`）の両方で最新位置へシーク

### チャットの自動全表示（`chat.js`）

1. `chat.js` がチャットの iframe（`youtube.com/live_chat`）に注入される
2. 表示切り替えドロップダウン（`#view-selector`）が描画されるまで待機
3. メニューを開き、「チャット（すべて表示）」の項目を選択（既に全表示なら何もしない）

## トラブルシューティング
(この拡張機能は永遠にWIPです)

**自動で最新位置に移動しない**
YouTubeのプレーヤーのDOM構造が変更された場合、シーク処理が機能しなくなることがあります。その場合はお手数ですが手動でシークバーを操作してください。

**チャットが自動で全表示に切り替わらない**
YouTubeのチャットUI（表示切り替えドロップダウン）のDOM構造が変更された場合、切り替え処理が機能しなくなることがあります。その場合はお手数ですが手動で「チャット」に切り替えてください。

**Windows、Linuxで動きますか？、BraveやEdgeでも動きますか？**
Mac、Chrome以外は動作未検証です。動かない場合は自力で何とかしてもらうかこのリポジトリごとコーディングエージェントに丸投げして聞いて下さい
