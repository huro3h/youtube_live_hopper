# YouTubeLiveHopper

YouTube Liveの配信一覧を表示し、配信終了時に自動で次のチャンネルへ切り替えるChrome拡張機能です。

<img height="500" alt="s_6" src="https://github.com/user-attachments/assets/948a23e4-3a85-4149-abdb-9e9e3a8138da" />


  
拡張機能の作者(@huro3h)はゲームのLive配信を流しっぱなしにしながら、同じゲームをすることが多いですが  
配信終了の度にコントローラーから手を離して、Live中のチャンネルを手動で切り替えるのが面倒と感じたのがモチベーションです  
  
ゲームや趣味のジャンルをBGM代わりに流し見したいときに使えます。  
Chrome Web Storeには公開していないため、手動でインストールして使用してください。

> [!WARNING]
> トピックチャンネル機能はYouTubeの非公式な仕組みを利用しています。YouTubeの仕様変更により、予告なく動作しなくなる場合があります。

> [!NOTE]
> 本ツールは個人利用・非商用を目的として作成したものです。利用にあたっては後述のNotesをご確認ください。

## 必要なもの

- Google Chrome
- YouTube Data API v3 のAPIキー（無料）

---

## 1. YouTube Data API v3 キーの取得

[Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com) からAPIキーを発行します。

1. プロジェクトを作成（または既存のものを選択）
2. `YouTube Data API v3` を有効化
3. 「認証情報」→「認証情報を作成」→「APIキー」でキーを発行
4. （推奨）「APIキーを制限」→ アプリケーションの制限で HTTPリファラー `https://www.youtube.com/*` を設定しておくと、万が一キーが漏洩した際の悪用リスクを軽減できます

APIキーは1日あたり **10,000ユニット** の無料枠があります。通常の使用であれば枠内に収まります。

| 操作 | 消費ユニット目安 |
|------|----------------|
| キーワード検索 1回 | 約100ユニット |
| トピックチャンネル登録 1件 | 約1ユニット |
| トピックチャンネル一覧更新 1件 | 約50ユニット |
| 動画情報取得 1件 | 約1ユニット |

## 2. インストール

```bash
git clone git@github.com:huro3h/youtube_live_hopper.git
```

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. クローンしたフォルダを選択

---

## 3. 初期設定

1. Chromeツールバーの YouTubeLiveHopper アイコンをクリック
2. 発行した APIキー を入力して「保存」
   - 保存後はヘッダーに「🔑 設定済み」バッジが表示されます
   - 再設定する場合はバッジをクリックすると入力欄が開きます

---

## 4. 使い方

### キーワード検索

入力欄にキーワードを入力して「検索 / 登録」を押すと、現在ライブ中の配信が視聴者数順に表示されます。

- スペース区切りで複数キーワードを指定できます
- `AND` / `OR` をラジオボタンで切り替えられます（デフォルトはAND）
- 検索結果は `🔍` セクションに表示され、ヘッダーの `✕` ボタンでクリアできます

### トピックチャンネルの登録

YouTubeのゲームタイトルや趣味ジャンルの `/live` ページ（例: `youtube.com/channel/UCxxxxxx.../live`）のチャンネルIDを入力欄に貼り付けて「検索 / 登録」を押すと登録されます。

チャンネルIDは `UC` で始まる24文字の文字列です。URLから抜き出して使用してください。

```
https://www.youtube.com/channel/UCVhW3DfOHgFBYG1Roqp7ukg/live
                                 ^^^^^^^^^^^^^^^^^^^^^^^^
                                 このIDをコピーして貼り付ける
```

- 登録したトピックチャンネルはリスト上部に `📌` セクションとして固定表示されます
- 複数登録するとチャンネルごとに独立したセクションで表示されます
- セクションヘッダーをクリックするとアコーディオン開閉できます
- 「✕ 解除」ボタンで登録を削除できます

### 再生と切り替え

- 一覧のチャンネルをクリックすると再生開始
- 配信終了を検知すると自動で次のチャンネルへ移動（「🔁 自動切り替え」がONの場合）
- 自動切り替えの順序：トピックチャンネル → キーワード検索結果の順で巡回
- 「⏮ 前へ」「次へ ⏭」で手動切り替えも可能
- 「🔄」ボタンで一覧を最新情報に更新

### 設定項目

| 設定 | 説明 |
|------|------|
| 🔁 自動切り替え（終了時） | 配信終了を検知して次のチャンネルへ自動移行 |
| ⚡ 常に最新位置から再生 | チャンネル切り替え時にライブの最新位置から再生（OFFにすると追っかけ再生が可能） |

## 仕組み

### ライブ一覧の取得

| ソース | 取得方法 |
|--------|---------|
| キーワード検索 | YouTube Data API v3 |
| トピックチャンネル | YouTubeの `/live` ページHTMLに埋め込まれた `ytInitialData` を解析 + Data API v3 で視聴者数・ライブ状態を確認 |

**トピックチャンネルの取得フロー**

1. background.js が `/channel/{ID}/live` のHTMLをfetch
2. HTMLに埋め込まれた `ytInitialData` からvideoIdを抽出
3. YouTube Data API v3 で各動画のライブ状態・視聴者数を確認
4. `liveBroadcastContent === 'live'` のものだけを視聴者数順で表示

この方法により、YouTube公式APIでは取得できない `/live` ページの表示内容とほぼ同等のライブ一覧を取得できます。

### 配信終了の検知

2つの方法を組み合わせています。

1. **DOM監視**（メイン）: YouTubeプレーヤーに `ended-mode` クラスが付与されたことを `MutationObserver` でリアルタイム監視。誤検知防止のため3秒後に再確認してから通知
2. **APIポーリング**（フォールバック）: 60秒ごとにData APIで `liveBroadcastContent` を確認

## トラブルシューティング
(この拡張機能は永遠にWIPです)

**トピックチャンネルの件数が少ない・0件になる**
YouTubeへのログイン状態や通信環境によって取得件数が変わる場合があります。YouTubeにログインした状態で拡張機能を再読み込み（🔄）してみてください。それでも改善しない場合、YouTubeの仕様変更によりこの機能が動作しなくなっている可能性があります。

**APIキーのエラーが出る・検索できない**
Google Cloud Consoleで1日あたりの無料枠（10,000ユニット）を超えていないか確認してください。また、APIキーにHTTPリファラー制限を設定している場合は `https://www.youtube.com/*` が含まれているか確認してください。

**配信終了しても自動切り替えが起きない**
YouTubeのプレーヤーのDOM構造が変更された場合、終了検知が機能しなくなることがあります。その場合は「次へ ⏭」ボタンで手動切り替えしてください。

**⚡ 常に最新位置から再生の設定を行ってもリンク先に飛んでもライブ配信中の時点にならない**  
お手数ですが画面から操作いただくか、拡張機能内の各リンクを何度かクリックして下さい

**▶ NOW PLAYINGのタイトル表示が再生中のLive配信動画と異なる**  
お手数ですが画面から操作いただくか、拡張機能内の各リンクを何度かクリックして下さい

**APIキーが何か、どうやってどこで何をすればいいかよくわかりません**  
ある程度Webの知識を有する人を前提にREADME.mdを作成しています。よくわからない場合はこのリポジトリごと生成AIに丸投げして聞いて下さい

**Windows、Linuxで動きますか？**  
Mac以外は動作未検証です。動かない場合はこのリポジトリごと生成AIに丸投げして聞いて下さい
